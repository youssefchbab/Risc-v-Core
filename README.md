# Risc-v Core
Contains a Risc-v core implemented in VHDL and verified using simulation.

1. This project is a part of a another project called "FPGA-Accelerated Network IDS with
RISC-V Co-Processor Integration" made with my colleague Salah Eddine Laifa the project was tested and verified to be working. 
2. For further details on design and/or the verification process check the PDF file attached to this repo in the documentation folder.
3. The Vhdl files are within the "Vhdl files" folder and can be copied and used with any software of your liking.
